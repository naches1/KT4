Заголовок первого уровня

HTML используется для создания структуры веб-страницы. С его помощью можно размещать заголовки, абзацы, списки и ссылки.

CSS отвечает за внешний вид документа. Через таблицу стилей задаются цвета, шрифты, фон и выравнивание элементов.

В данном документе показаны основные элементы разметки, которые часто применяются при создании простых сайтов.
